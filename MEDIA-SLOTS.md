## Integration Instructions (for Codex)

When delivering a new hero image:

1. Place file in `assets/` with naming convention: `hero-{service-name}-1400x600.jpg`
2. Optimize: max 150KB, JPEG quality 80-85
3. Claude will add the HTML banner using this template:

```html
<!-- Service Hero Banner -->
<div class="container" style="margin-top: -1.5rem; margin-bottom: 2rem;">
  <div class="service-hero-banner">
    <img src="assets/hero-{service}-1400x600.jpg" alt="{Service Name}" data-en-alt="{EN alt}" data-ja-alt="{JA alt}" loading="eager">
  </div>
</div>
```

Insert after the closing `</section>` of the `.service-page-hero` block.
